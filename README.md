# Baocaosx - Hệ Thống Báo Cáo Sản Xuất Trực Tuyến VICO

Hệ thống quản lý và báo cáo sản xuất trực tuyến - Phân xưởng Nhiệt luyện (VICO).

## Tính năng
- Quản lý và nộp báo cáo ca sản xuất trực tuyến
- Tổng hợp số liệu sản xuất tự động theo ngày và theo kỳ
- Xuất file báo cáo Excel chuẩn mẫu
- Quản lý phân quyền tài khoản (Admin, Ca trưởng)
